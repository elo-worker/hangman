# Игра «Виселица» (Hangman) на Python 🎮

Классическая консольная текстовая игра **«Виселица»**, написанная на Python. Программа загадывает случайное слово из списка, а игрок должен угадать его по буквам или назвать слово целиком за ограниченное количество попыток.

## ✨ Особенности проекта
* **Угадывание по буквам и целиком:** можно открывать слово по одной букве или рискнуть и ввести всё слово сразу.
* **Интерактивная визуализация:** состояние виселицы динамически отрисовывается в консоли после каждого хода.
* **Защита от повторов:** игра помнит, какие буквы и слова вы уже вводили, и не отнимает за них попытки.
* **Бесконечный режим:** после завершения раунда программа предлагает сыграть ещё раз без перезапуска скрипта.
* **Регистронезависимость:** ввод работает корректно как со строчными, так и с заглавными буквами.

## 🚀 Как запустить игру

### Требования
Для запуска игры вам понадобится установленный **Python версии 3.x**.

### Инструкция по запуску
1. Склонируйте репозиторий или скачайте файл с кодом:
   ```bash
   git clone https://github.com
   cd hangman-game
   ```
2. Запустите скрипт через терминал или командную строку:
   ```bash
   python hangman.py
   ```

## 🕹️ Правила игры
1. У вас есть **6 попыток**, чтобы совершить ошибку. При каждой ошибке дорисовывается элемент виселицы.
2. Вводите по одной букве на русском языке. Если буква есть в слове — она откроется.
3. Если вы знаете слово целиком, вы можете ввести его сразу (длина ввода должна совпадать с длиной загаданного слова).
4. Игра завершается победой, если слово полностью угадано, или проигрышем, если человечек на виселице полностью отрисован.
